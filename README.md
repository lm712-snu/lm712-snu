## Featured work

### Mathematics of Computer Vision Language Models
**Research / thesis project** · [Repository](https://github.com/lm712-snu/cvlm-thesis) · [Thesis website source](https://github.com/lm712-snu/lakshyathesis)

Exploring the mathematical ideas behind computer vision and vision-language models, with an emphasis on making core concepts understandable through explanations and interactive learning material.

**Focus:** image processing, convolution, CNNs, neural-network optimisation, and the path toward vision transformers.

### Mathematical Foundations and Machine Learning for Chess Position Evaluation
**Machine learning research project** · [Repository](https://github.com/lm712-snu/Mathematical-Foundations-and-Machine-Learning-for-Chess-Position-Evaluation)

A project connecting chess-position features with mathematical modelling and supervised learning. The project explores how board structure and engineered features can be used to estimate position evaluations.

### AuralMind 2.0 — Multimodal Music Intelligence
**Prototype / scaffold** · [Repository](https://github.com/lm712-snu/LAKSHYAMISHRA-LLM-MAT496)

An exploratory music-intelligence project designed around a LangGraph-orchestrated architecture, with FastAPI and Streamlit components. The repository currently describes a starter scaffold with placeholders; external integrations and audio-processing components require further implementation and API credentials.

**Focus:** agent workflows, tool integration, API design, and multimodal music applications.

### Contract Analyzer & Legal QA Agent
**LLM application · verification and development ongoing** · [Repository](https://github.com/lm712-snu/LAKSHYAMISHRA-CAPSTONEPROJECT-MAT496)

An intended legal-document assistant exploring retrieval-augmented question answering, semantic search, structured outputs, and tool-assisted extraction. The repository roadmap still contains TODO items, so features should be treated as planned until their implementation is verified.
